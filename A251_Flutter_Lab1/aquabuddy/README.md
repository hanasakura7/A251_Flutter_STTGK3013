# aquabuddy

AquaBuddy is a simple Flutter application to calculate the daily water intake based on weight, age, activity level, and current weather. It will display the daily water intake needed to consume every day, in litres. 

Reference for input: [Water Intake Calculator | Hydration Calculator | ATHLEAN-X](https://learn.athleanx.com/calculators/water-calculator)

The application contains two files which are main.dart and mainscreen.dart. The splash screen is at the main file, and it appears for 2 seconds. The mainscreen.dart appears as the list of inputs that the user will need to enter, and the calculateWater() method, under the same file, will perform validation, error handling and display the result (output) as pop-up. 

Widgets used: Text, TextField, Column, Row, Container

## INPUT

The user needs to enter these 4 inputs, which are especially from text field and drop down button, and the variables are as below:

Text field: Weight (kg), Age 

DropDown button: Activity Level, Weather Today 

## PROCESS

Once the user clicks the Calculate button, it will go through a list of validations. 

The list of validations are as follows:
Checks to ensure text field of age/weight is not empty
It checks either:
	- weight is more than 0 and less than or equal to 200 kg, or null value.
	- age is more than 0 and less than or equal to 120, or null value.

If it does not pass the validation, a display message (SnackBar) will be shown, asking users to reenter.

If the values entered passed the validation process, it will proceed to perform calculation.
Calculation is as follows:

Base Water = Weight * Value of Water in litres (according to age range).
Final Water Intake = Base Water + Water Intake Per Activity (intensity) + Water Intake (Depending on Weather)

The value of water intake in double will be converted to String, rounded up to 2 decimal places.
 
Clicking the ‘Reset’ button will reset all values in the text field, and set the default value of Activity Level to ‘Low’ and Weather Today to ‘Normal’. 

## OUTPUT

The value of water intake will be displayed as below pop up, telling the user the estimated amount of water intake that needs to be consumed daily.
